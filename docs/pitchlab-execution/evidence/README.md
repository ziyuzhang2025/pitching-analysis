# Evidence conventions

Keep large/raw artifacts in their existing output/storage directories; keep private media and personal identifiers out of version control. Record sanitized metadata and relative artifact references/checksums here.

Every verification entry needs date, source revision, task, environment, command or manual procedure, observed outcome, coverage limits and attribution. An inspected test file is not an executed test. A saved output is not a fresh inference run.

Use [baseline manifest](baseline-manifest.md), [verification log](verification-log.md), [milestone acceptance](milestone-acceptance.md), and [release acceptance](release-acceptance.md).
